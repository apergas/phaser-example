# Arreglos y mejoras sin fase

Fallos y mejoras vistos jugando que no son de ninguna fase de las hojas de ruta. Cada uno tiene su ficha aquí; su estado se sigue en [`PROGRESS.md`](../PROGRESS.md).

- Ramas: `bugfix/PROJECT-X-<descripción>` para un fallo y `feature/PROJECT-X-<descripción>` para una mejora, desde la rama de integración donde está el código. Commits `[PROJECT-X]: …`.
- Al empezar uno, `boost:writing-plans` convierte su ficha en plan, como en las fases.
